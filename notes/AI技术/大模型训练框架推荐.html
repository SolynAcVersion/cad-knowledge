ms-swift（魔搭社区）github.com/modelscope/ms-swift

阿里达摩院魔搭社区开源的一站式大模型训练/微调/部署框架。 在本次实测中，它是唯一同时满足全部需求的框架：功能覆盖 6/6 项满分， 近 3 天内有代码提交，19 天前发布新版本，且对 Qwen 系列模型有原生优先支持 （毕竟是同门生态）。

为什么它最合适：① 支持 200+ 文本模型与 100+ 多模态模型（含 Qwen3-VL、Qwen3.8、InternVL 等）； ② 训练方法覆盖 CPT/SFT/DPO/GRPO/PPO/KTO/RM 全链路；③ LoRA/QLoRA/LoRA+ 及全参数训练都支持； ④ 底层兼容 DeepSpeed / FSDP / Megatron 多种并行方案；⑤ 中文文档完善，社区活跃。

一句话推荐：如果只装一个框架，选 ms-swift。 它把「LLM + VLM + SFT + RL + LoRA + 全参数 + 分布式」全塞进了一套统一命令行里， 且与 Qwen 生态同源，踩坑最少。

备选方案：按场景选择

🥈 LLaMA-Factory github.com/hiyouga/LLaMA-Factory · ⭐75,116

  • 优势：生态最大、教程最多、WebUI 最友好，新手零代码即可上手微调；功能覆盖同样 6/6。
  • 注意：实测最近一次正式发版距今 120 天（代码仍有提交，但发版节奏偏慢）；RL 能力以 DPO/KTO/PPO 为主，GRPO 等新算法跟进稍慢。
  • 适合：以 SFT / LoRA 微调为主的团队，或需要可视化界面降低使用门槛的场景。

🥉 veRL（字节跳动）github.com/volcengine/verl · ⭐23,662

  • 优势：强化学习专精，GRPO/PPO 等 RL 算法实现最前沿，7 天前刚发新版，被大量 RL 论文采用。
  • 注意：定位是 RL 训练框架，全参数 SFT 不是它的主战场；建议与 ms-swift 搭配使用。
  • 适合：主攻 RLHF / GRPO 后训练、追求算法前沿的团队。

💡 Unsloth github.com/unslothai/unsloth · ⭐76,884

  • 优势：单卡微调速度最快（宣称 2-5 倍加速、显存降低 70%），1 天前刚发版，维护极活跃。
  • 注意：强项是 LoRA/QLoRA 单机微调，分布式大规模训练不是重点。
  • 适合：个人开发者、单卡/双卡环境做快速微调实验。

🔧 TRL（HuggingFace 官方）github.com/huggingface/trl · ⭐19,403

  • 优势：HuggingFace 官方出品，与 transformers/datasets 生态无缝衔接，2 天前刚发版，代码质量高。
  • 注意：偏底层库，需要自己写训练脚本；VLM 支持较弱，无开箱即用的多模态训练流程。
  • 适合：需要深度定制训练逻辑、追求代码可控性的团队。

ms-swift 快速上手

安装支持 pip 一键安装，也可从源码安装获取最新特性。
# 基础安装
pip install ms-swift -U
# 需要 RL 训练时，安装额外依赖
pip install ms-swift[llm] -U
LoRA 微调（LLM）一行命令完成，支持 Qwen 全系列。
swift sft \
    --model Qwen/Qwen3-8B \
    --train_type lora \
    --dataset 'AI-ModelScope/alpaca-gpt4-data-zh#500' \
    --torch_dtype bfloat16 \
    --num_train_epochs 1 \
    --lora_rank 8 \
    --learning_rate 1e-4 \
    --output_dir output
多模态微调（VLM）只需换模型和数据集，命令结构一致。
swift sft \
    --model Qwen/Qwen3-VL-8B-Instruct \
    --train_type lora \
    --dataset 'AI-ModelScope/LaTeX_OCR#2000' \
    --torch_dtype bfloat16 \
    --num_train_epochs 1 \
    --output_dir output_vl
强化学习（GRPO）内置 GRPO/PPO/DPO 等算法，直接可跑。
swift rlhf \
    --rlhf_type grpo \
    --model Qwen/Qwen3-8B \
    --dataset 'AI-ModelScope/gsm8k' \
    --reward_funcs accuracy \
    --output_dir output_grpo
全参数训练与分布式去掉 --train_type lora 即为全参数；加 --deepspeed zero3 等参数启用分布式。
swift sft \
    --model Qwen/Qwen3-8B \
    --train_type full \
    --deepspeed zero3 \
    --dataset 'AI-ModelScope/alpaca-gpt4-data-zh' \
    --output_dir output_full

组合建议：日常 SFT/LoRA 微调用 ms-swift； 如果要做大规模 RL 前沿实验，可搭配 veRL； 如果只有单卡想跑得飞快，试试 Unsloth。三者并不冲突，可按阶段切换。
