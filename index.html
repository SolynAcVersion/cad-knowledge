🧭 两套并行体系

ms-swift（Transformers 系）

通用易用，覆盖绝大多数模型：DDP、device_map、DeepSpeed ZeRO、FSDP/FSDP2、序列并行（Ulysses / Ring-Attention）。

Megatron-SWIFT（Megatron-LM 系）

大规模集群 / MoE 模型极致提速：TP、PP、SP、CP、ETP、EP、VPP 全套并行策略。

⚡ 训练侧并行框架明细

并行框架关键参数说明
DDP 数据并行ddp_backend / ddp_timeout最基础多卡并行，backend 支持 nccl/gloo/mpi 等，默认自动选择
device_map 模型并行--device_map auto按层切分权重到多设备，适合快速验证；Liger kernel 不支持
DeepSpeed ZeRO--deepspeed zero2/zero3zero0~3 及 offload 版本；支持 ZeRO++（zero_hpz_partition_size）与 AutoTP 张量并行
FSDP / FSDP2推荐--fsdp 'fsdp2'PyTorch 原生分布式方案，fully_shard 新实现，省显存、易用
序列并行--sequence_parallel_size NUlysses + Ring-Attention，超长文本训练降显存；支持 CPT/SFT/DPO/GRPO

🚀 Megatron-SWIFT 并行策略

TP · 张量并行

把矩阵运算切到多卡，单层并行加速。

PP · 流水线并行

按层分段流水执行，VPP 虚拟流水线进一步提效。

EP / ETP · 专家并行

MoE 模型专家分布到多卡，训练提速关键。

SP / CP · 序列 / 上下文并行

超长序列切分，突破上下文长度限制。

支持任务：CPT / SFT / GRPO / DPO / KTO / RM / GKD / Embedding / Reranker / 序列分类；支持全参数与 LoRA，覆盖 300+ 纯文本、100+ 多模态模型。

🛠️ 快速上手命令

# DeepSpeed ZeRO2
swift sft --deepspeed zero2 ...
# FSDP2（PyTorch 原生）
swift sft --fsdp 'fsdp2' ...
# 序列并行（Ulysses + Ring-Attention）
swift sft --sequence_parallel_size 4 ...
# Megatron 并行（TP=2）
NPROC_PER_NODE=8 megatron sft \
  --tensor_model_parallel_size 2 ...
